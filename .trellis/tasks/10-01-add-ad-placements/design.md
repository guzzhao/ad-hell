## 2. 数据与状态设计

### 2.1 素材与品牌虚构（合规红线）
所有新增的原生广告文案、品牌均自创，不得包含任何真实企业商标。
在 `src/data/creatives.ts` 中复用或扩展合规素材 ID：
- `loan-fast` (速银花 - 最高可借20万)
- `loan-quota` (钱多多 - 额度待领取)
- `game-legend` (龙渊传奇 - 一刀9999级)
- `game-retro` (霸业复古)
- `slim-seven` (轻盈日记 - 7天瘦10斤)
- `health-bp` (康寿堂 - 免费领血压仪)
- `dating-nearby` (近邻缘 - 附近3人想认识你)
- `shop-99` (拼一拼优选 - 9.9包邮到家)
- `fake-system` (系统提示 - 内存不足立即清理)
- `splash-mall` (闪购商城)
- `splash-video` (趣看短视频)

### 2.2 App 状态与描述 (`src/data/apps.ts`)
- 更新 `APPS` 数组中的商业应用 `note`，移除“这里一个广告都没有”，改为反映现实应用特征的简述；
- 更新 `HOME_GROUP_TITLES`，将“本来就该干干净净的 / 平时广告最多的”改为“系统工具类应用 / 常用商业应用”，体现全体沦陷。

### 2.3 状态管理与交互钩子 (`src/stores/storm.ts`)
- `adsEnabled`: 默认开启或在应用打开时确保原生广告位生效；
- `triggerLanding()`: 原生广告的 CTA 按钮与广告主体点击时统一拉起 `landingOpen.value = true`，使用户体验到典型的“误触直接打开落地页”烦躁感；
- `triggerMisclick(extraAds)`: 假关闭按钮（如微型 × 或骗人打叉）点击时增加 2~4 个随机弹窗。

## 4. 兼容性与质量保证

1. **测试防护**：
   - 现存 135 个测试（包含素材黑名单、风暴单调性、烟雾测试）必须无破坏；
   - 新增组件及修改组件必须符合 Vue 3 + TypeScript 强类型标准；
2. **性能与动效**：
   - 所有悬浮动画与小黄车闪烁遵循 `useReducedMotion` 偏好设置，若开启减少动效则取消高频摇晃；
3. **安全与沙箱**：
   - 严禁触发任何真实 `window.open` 或外部 url，全部在虚拟手机壳内流转。
